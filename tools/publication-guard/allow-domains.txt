# Domains the public shape checker accepts in hostnames and e-mail addresses.
# Data, not code. Format: `<kind> <value>`; `#` starts a comment.
#
#   domain  a registrable domain; every host under it is accepted. `example.*`
#           accepts example.<any tld>. Reserved names without a dot (`test`,
#           `invalid`, `localhost`, `example`) are accepted here too.
#   email   a domain accepted on the right-hand side of an e-mail address.
#           A domain listed only as `domain` is NOT an accepted mailbox host:
#           a vendor's site in a link is routine, a mailbox at it is a person.
